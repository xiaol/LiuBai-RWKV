# LiuBai-H 3B on MSVAE latents with full-rank NAR deltas (20k steps) vs prod1 (VAE v5 + LoRA, 30k), 2026-11-05

**Play in the browser:** https://raw.githack.com/xiaol/LiuBai-RWKV/main/samples/msvae_full1_20k_vs_prod1_20261105/player.html

Held-out real songs; 4 s real prompt (encoded from its own audio only), then 20 s generated by the RWKV-7 3B block-flow cursor LM.
MSVAE runs: latent = MSVAE (ASLP-lab, 25 Hz x 64, decoded to 48 kHz stereo), NAR rows use full-rank zero-init weight deltas (no LoRA), 0.32 s blocks.
Training: steps 0–5k delta lr 6e-5, 5k–10k delta lr 1.5e-4, 10k–20k also MSVAE's linguistic half (dims 32–63) weighted x3 in the flow loss.
prod1 runs: our VAE v5 latent (12.5 Hz), rank-64 LoRA NAR, 30k steps (same clips as samples/prod1_3b_vs_208m_20261103).
`own` = given the clip's own lyrics, `swap` = given another clip's lyrics. Number = Whisper letter CER vs the lyrics it was given (lower is better; original recordings 0.43 median, MSVAE round trip 0.47).
Clips 0–11 in eval order (not cherry-picked). Only generated audio is published.
